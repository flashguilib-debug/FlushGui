FlashGui 0.1.6

Costruisci interfacce desktop con il sorriso. Componenti già pronti, layout proporzionale, temi personalizzabili.

Python 3.7+ wxPython Phoenix Windows · macOS · Linux MIT License

✨ Perché FlashGui?

Hai presente quando vuoi creare una piccola app desktop in Python e ti scontri con la complessità di Tkinter o la verbosità di wxPython? FlashGui nasce per darti calcolatrice, blocco note, paint, orologio, calendario e un motore di ricerca file già funzionanti in 3 riche di codice. Se vuoi costruire la tua interfaccia da zero, il componente WINDOW ti permette di posizionare qualsiasi widget usando coordinate proporzionali (0.0 → 1.0) e i font si ridimensionano da soli. Tutto con un look pulito, moderno e completamente personalizzabile.

💡 Idea: FlashGui è perfetto per prototipi rapidi, tool interni, o per chi si avvicina alla programmazione GUI e vuole risultati immediati senza studiare mille manuali.

📦 Installazione

pip install FlashGui

wxPython e charset_normalizer vengono installati automaticamente. Nessun'altra dipendenza manuale.

✅ Compatibile con: Windows 10/11, macOS (Intel e Apple Silicon), Linux con wxPython supportato. Richiega Python 3.7 o superiore.

📚 Dipendenze

FlashGui è costruito sopra wxPython Phoenix (wxWidgets) e utilizza charset_normalizer per il rilevamento automatico delle codifiche nel blocco note. Entrambe vengono installate automaticamente con pip. Per SEARCHER, le richieste HTTP usano la libreria standard urllib — nessun pacchetto aggiuntivo necessario.

🧮 CALCULATOR

Una calcolatrice completa con display, 20 pulsanti e gestione degli errori. Puoi cambiarne ogni singolo aspetto e agganciare le tue funzioni a ogni tasto.

sizetuple (w, h)(3, 2)Dimensioni relative allo schermo: il valore indica in quante parti dividere lo schermo. Es. (3,2) → larghezza = schermo÷3, altezza = schermo÷2.

Metodo .Logic()

Ogni parametro accetta una funzione senza argomenti (o None per comportamento predefinito).

ParametroDescrizione
button_0_command … button_9_commandFunzione chiamata alla pressione del tasto numerico corrispondente.
button_dot_commandCallback per il tasto punto decimale.
button_plus_commandCallback per +.
button_minus_commandCallback per −.
button_mul_commandCallback per ×.
button_div_commandCallback per ÷.
button_eq_commandCallback per = (sostituisce completamente il comportamento eval predefinito).
button_C_commandCallback per Clear.
button_DEL_commandCallback per Delete.

Metodi pubblici

  • GetText() → str — restituisce il testo attuale nel display.
  • SetText(testo) — imposta il display e l'espressione interna.
  • AppendText(testo) — aggiunge testo in coda all'espressione corrente.
  • Clear() — svuota display e memoria.
  • AddTimer(ms, command) — avvia un timer one-shot che esegue command dopo ms millisecondi.
  • run() — avvia il loop principale dell'applicazione (bloccante).

📘 Esempio

calculator_demo.py
from FlashGui import CALCULATOR

def mio_callback():
    print("Hai premuto un tasto personalizzato!")

calc = CALCULATOR(title="La mia calcolatrice", size=(3,2), color=(50,50,60), style="dark")
calc.Edit(
    button_eq_bg=(200,50,50),
    button_eq_fg=(255,255,255),
    entry_bg_color=(30,30,40),
    entry_text_color=(0,200,0),
    message_error="ERRORE"
)
calc.Logic(button_0_command=mio_callback)
calc.run()

📘 Esempio

notepad_demo.py
from FlashGui import NOTEPAD

note = NOTEPAD(title="Editor Avanzato", style="dark")
note.Edit(font_size=13)
note.Logic(on_text_change_command=lambda: print("Testo modificato!"))
note.run()

🔍 SEARCHER

Un potente motore di scansione ed indicizzazione locale per file e cartelle, combinato con un modulo client leggero che sfrutta urllib per interrogare endpoint e API remote senza dipendenze di terze parti.

Costruttore

SEARCHER(title="Searcher", size=(2,1.8), style="light")

Metodi pubblici

  • SearchLocalFiles(directory, extension=None) — Esegue una scansione ricorsiva all'interno della directory indicata, filtrando opzionalmente per estensione (es. .py).

  • GetFoundItems() → list — Restituisce l'elenco dei percorsi o delle stringhe trovate nell'ultima sessione di ricerca.

🪟 WINDOW (La tela bianca)

Se i moduli pronti all'uso non bastano, WINDOW ti mette a disposizione una finestra vuota dotata di un sistema di coordinate proporzionali.

Invece di impazzire con i pixel o con i complessi Sizer nidificati di wxPython, puoi posizionare i tuoi componenti indicando valori decimali compresi nell'intervallo $0.0 \le x, y \le 1.0$. I font e i widget stessi si ridimensioneranno proporzionalmente al variare delle dimensioni della finestra, mantenendo sempre intatto il layout matematico stabilito originariamente.

Costruttore

WINDOW(title="Custom Grid", size=(2,2), color=(245,245,240), icon=None, maximized=False, style="light")

➕ Metodi Add…

Ogni metodo Add inserisce un elemento grafico all'interno del motore a coordinate proporzionali. Restituiscono un identificatore univoco (stringa intera o istanza) utilizzato per manipolare l'elemento in un secondo momento.

AddButton(text, pos, size, command=None) Crea un pulsante cliccabile. pos=(x, y) e size=(w, h) usano float proporzionali.
AddText(text, pos, size, font_bold=False) Visualizza una stringa di testo statico (Label) con font auto-scalante.
AddInput(pos, size, placeholder="", multiline=False) Inserisce un campo di testo per l'input dell'utente (singola linea o area di testo multilinea).
AddCheckbox(text, pos, size, command=None) Crea una casella di spunta booleana.
Metodo Add specialeArgomenti principaliDescrizione
AddListbox(items, pos, size, command=None)items (list of str)Genera una lista di elementi selezionabili con barra di scorrimento verticale.
AddImage(image_path, pos, size)image_path (str)Carica un file PNG/JPG e lo scala proporzionalmente al contenitore.

🛠️ Utility e Modifica dei Widget Dinamici

Puoi alterare lo stato dei controlli inseriti all'interno dell'istanza WINDOW in qualsiasi momento dell'esecuzione del programma tramite i seguenti metodi di istanza dedicati:

  • GetWidgetValue(widget_id) → Restituisce il valore corrente contenuto nell'elemento (il testo inserito in un Input, lo stato booleano di un Checkbox, la riga selezionata in un Listbox).
  • SetWidgetValue(widget_id, new_value) → Modifica dinamicamente il valore o la stringa visualizzata dal componente specificato.
  • SetWidgetColor(widget_id, bg_color=None, fg_color=None) → Applica combinazioni RGB personalizzate locali a un singolo widget della griglia.
  • RemoveWidget(widget_id) → Distrugge l'elemento grafico e lo rimuove immediatamente dallo schermo e dall'albero di rendering proporzionale.

📘 Esempio Pratico Completo con WINDOW

custom_dashboard.py
from FlashGui import WINDOW

def saluta():
    nome = app.GetWidgetValue(input_id)
    app.SetWidgetValue(label_id, f"Ciao, {nome}! Benvenuto in FlashGui.")

app = WINDOW(title="Pannello Personalizzato", size=(2,1.8))

# Posizionamento ad assi frazionari (0.0 -> 1.0)
app.AddText("Inserisci il tuo nome completo:", pos=(0.1, 0.1), size=(0.8, 0.08))
input_id = app.AddInput(pos=(0.1, 0.2), size=(0.8, 0.1), placeholder="Scrivi qui...")

btn_id = app.AddButton("Genera Saluto", pos=(0.3, 0.4), size=(0.4, 0.12), command=saluta)
label_id = app.AddText("", pos=(0.1, 0.6), size=(0.8, 0.1))

app.SetWidgetColor(btn_id, bg_color=(26, 107, 201), fg_color=(255, 255, 255))
app.run()

🔄 Filosofia Comune: .run() · .Edit() · .Logic()

Tutti i moduli nativi presenti nella suite software FlashGui ereditano la medesima struttura logica di interazione sequenziale, divisa rigorosamente in tre fasi:

  1. Inizializzazione Configurazione: Definizione dei vincoli fisici e del titolo nel costruttore principale.
  2. Fase .Edit() (Aspetto): Configurazione opzionale dello stile visivo, palette di colori e traduzioni dei componenti testuali.
  3. Fase .Logic() (Comportamento): Aggancio delle funzioni callback scritte in Python puro agli eventi di interfaccia dell'applicazione.
  4. Esecuzione .run(): Apertura della finestra e avvio del ciclo principale di gestione degli eventi (Main Event Loop). Questo metodo è bloccante.

⏱️ Gestione dei Timer Asincroni

Tutti i componenti mettono a disposizione il metodo di istanza AddTimer(ms, command). Questo genera un timer asincrono non bloccante che esegue la funzione passata come parametro dopo l'intervallo di tempo indicato (espresso in millisecondi).

Poiché i callback dei timer vengono eseguiti all'interno del thread principale della GUI gestito da wxPython, è possibile modificare in totale sicurezza lo stato e i testi di qualsiasi widget senza incorrere in crash di thread-safety.
